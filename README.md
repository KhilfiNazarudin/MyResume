# My LaTeX Resume

A clean, single-column resume built with LaTeX (XeLaTeX). Includes sections for
technical skills, professional experience, extracurriculars, and education.

## Compiling

Requires a TeX distribution (e.g. [MiKTeX](https://miktex.org) or TeX Live) with `xelatex`.

```bash
xelatex mohamedkhilfi_resume.tex
```

## Notes

- Contact info has been removed/placeholder-ed for this public version.
- Feel free to use this as a template for your own resume.
